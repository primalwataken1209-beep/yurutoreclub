# ゆるトレ倶楽部 v51.4.2（最終版）— 新規登録のパスワードを8文字以上に（ログインは従来どおり）

ベース：`yurutore_v51_4_1_private_insert_security_clean`
（アップロードいただいたZIPが、こちらで作成した v51.4.1 とバイト単位で同一であることを確認したうえで作業しています）

Supabase 本番の `Minimum password length = 8` にアプリ側を合わせました。
**8文字チェックは「新規登録」のときだけ**行い、**ログインでは文字数で弾きません**。
6〜7文字のパスワードを使っている既存ユーザーは、今までどおりログインできます。

> Supabase 側（Dashboard / SQL / migration / RLS / Storage / Edge Function）は**一切変更していません**。
> 今回はフロントエンドのみの修正です。

---

## 1. 仕様

| 場面 | 挙動 |
|---|---|
| **新規登録** | 8文字未満は**アプリ側で拒否**（サーバーへ送信もしない）。8文字以上は従来どおり送信 |
| **新規登録画面の表示** | 日本語「8文字以上」／English「8 characters or more」。エラーも「パスワードは8文字以上で入力してください」／「Your password needs at least 8 characters.」 |
| **ログイン画面の表示** | パスワード欄のヒントは 日本語「パスワード」／English「Password」（最終版で出し分け） |
| **ログイン** | **文字数によるフロント側の拒否をしない**（6文字でも7文字でもSupabaseへ送る） |
| **ログインの成否** | **Supabase 側の判定に任せる**（正しければログイン成功、間違っていれば従来の認証エラー） |
| **Googleログイン** | 変更なし |
| メールアドレス未入力・形式不正・パスワード未入力のチェック | 従来どおり（新規登録・ログインとも） |

## 3. 変更した箇所（13か所）

### 3-1. 判定関数（`index.html` 2670 付近）

```js
function validateAuthInput(email,pass,mode){      // ← 第3引数 mode を追加
  ...
  /* 【v51.4.2】8文字以上のチェックは「新規登録」のときだけ行う。
     ・新規登録 … Supabase本番の Minimum password length = 8 に合わせて、送信前に止める
     ・ログイン … 文字数では弾かない。6〜7文字のパスワードを使っている既存ユーザーが
                  今までどおりログインできるようにするため（正否の判定はSupabaseに任せる）
     mode を渡さずに呼んだ場合は、安全側（8文字以上を必須）として扱う。 */
  if(mode!=='login' && p.length<8) return t('msg.passShort');
  return null;
}
```
- `mode` 未指定のときは8文字以上を必須にする（安全側の既定）ため、将来ほかの場所から呼ばれても緩くなりません。

### 3-2. 呼び出し4か所

| # | 場所 | 変更後 |
|---|---|---|
| 2 | `handleLogin`（ログイン処理） | `validateAuthInput(email,pass,'login')` |
| 3 | `handleRegister`（新規登録処理） | `validateAuthInput(email,pass,'signup')` |
| 4 | 登録／ログイン画面のボタン | `validateAuthInput(email,pass,mode==='register'?'signup':'login')` |
| 5 | ウェルカム画面のボタン | 同上（同じ書き方） |

画面側の2か所は、その画面がもともと持っている `mode`（`'register'` / `'login'`）をそのまま渡しているだけです。

### 3-3. 文言4か所（6文字 → 8文字）

| # | 行 | 変更前 → 変更後 |
|---|---|---|
| 6 | 2136 | `passShort:'パスワードは6文字以上で入力してください'` → `…8文字以上…` |
| 7 | 2223 | `passwordPh:'6文字以上'` → `'8文字以上'` |
| 8 | 2420 | `'Your password needs at least 6 characters.'` → `…at least 8 characters.` |
| 9 | 2506 | `'6 characters or more'` → `'8 characters or more'` |

**「6文字」→「8文字」に変更した件数：4件（文言）＋判定1件＝5件**（`app.js` は同期コピーなので同数）

### 3-4. パスワード欄のplaceholder出し分け（最終版で追加・4か所）

| # | 場所 | 変更内容 |
|---|---|---|
| 10 | 日本語辞書 `auth`（2223行） | `passwordPhLogin:'パスワード'` を**追加** |
| 11 | 英語辞書 `auth`（2506行） | `passwordPhLogin:'Password'` を**追加** |
| 12 | 登録／ログイン画面の入力欄 | `placeholder={t(mode==='login'?'auth.passwordPhLogin':'auth.passwordPh')}` |
| 13 | ウェルカム画面の入力欄 | 同上（同じ書き方） |

- 追加した i18n キーは **`auth.passwordPhLogin` の1つ**（日英それぞれに1行）。ja / en とも **522キーで完全一致**。
- 既存の `auth.passwordPh`（「8文字以上」／「8 characters or more」）は変更なし。新規登録タブではこれまでどおりこちらを表示します。
- 画面がもともと持っている `mode`（`'register'` / `'login'`）で切り替えるだけで、タブの見た目・動き・認証ロジックは変えていません。
- **認証ロジック（`validateAuthInput` と呼び出し4か所）は前回納品と完全に同一**です（機械比較で確認済み）。

## 7. 補足

- Supabase の最低文字数はこれから設定するパスワードに適用されます。既存の短いパスワードはそのまま有効で、今回の修正によりログインも従来どおり通ります。
