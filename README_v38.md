## 3. どの条件でどれが出るか（優先順位）

```
1. 節目（連続 3/7/10/30/50/100 回）→ 節目リアクション
2. 久しぶり（前回から3日以上あいた）→ おかえりリアクション
3. 抽選  5%  → 激レア
        25%  → レア
        70%  → 通常枠
             └ 通常枠の内訳（時間帯で重みが変わる）
                深夜 55% / 夜 35% / 朝昼 20% … 時間帯リアクション
                残りの約45% ………………… 運動種類別リアクション
                それ以外 …………………… 通常7種からランダム
```
20,000回の抽選テスト実測：激レア 5.0% / レア 24.7% / 種目別 31.7% / 時間帯 13.9% / 通常 24.7%。

### パンジローが覚えている「ひとこと」
褒めメッセージの下に、短い1行だけ添えます（毎回は出ません・約70%）。

- 前回と同じ運動 →「この前もストレッチだったね！」
- 今月3回目以上 →「今月もう5回目だよ。地味にすごい！」
- 直近5件中3件が同じ種目 →「最近ウォーキング多いね〜！」
- 2〜3日ぶり →「また会えてうれしい！」
- 初回 →「はじめての記録、ちゃんと見てたよ🐼」

## 4. 家具解放との連携

記録の**前後で解放済み家具のidを比較**し、増えていたら演出の最後に表示します。

```
あれ……？
パンジローの部屋で何か起きたみたい🐼
[ 見に行く ]
```

「見に行く」→ ホームへ戻り、**パンダルームが全画面で自動オープン**します。
その後は既存の解放演出（おとどけ／`fur-appear` の光る演出／パンジローが喜ぶ 1.6秒）がそのまま動きます。

- 家具の解放条件・保存キー（`yurutore_room_seen_unlocks_v1_*`）・部屋側のコードは**一切変更していません**。差分を見るだけです。
- 自動オープンの合図は使い捨て（開いたら親側で 0 に戻す）なので、あとからホームに戻っても勝手には開きません。

## 5. 演出の長さとスキップ

| フェーズ | 時間 |
|---|---|
| 軽いフラッシュ | 0.26秒 |
| パンジロー登場 | 0.5秒 |
| メインリアクション | 約1.4秒 |
| 褒めメッセージ＋導線 | 以降は自動で消えない |

- **画面のどこをタップしても最後まで飛ばせます**（右上に「スキップ」ボタンも常設）。
- パンジローは画面幅の **約62%**（激レア/ドアップ時 74%）。高さ680px未満の端末では54%に自動縮小。
- アニメーションは `transform` 中心のCSSのみ。動画・新規ライブラリ・追加画像はゼロ。
- `prefers-reduced-motion: reduce` の端末では演出を全停止し、内容だけ即表示します。
- 音は追加していません（無音前提）。将来追加できるようフェーズ管理だけ分離済み。

パンジローの絵は既存の `assets/panda-room/v30/panda30_*.webp` を使用。
読み込み失敗時は `panda30_normal.webp` →それも失敗したら絵文字🐼、の二段フォールバックで必ず表示されます。

## 8. 今後改善できそうな部分

- **「記録して投稿する」経路の演出**：現在この経路は従来どおりタイムラインへ直行し、演出が出ません。二重投稿を避けるため今回は変更しませんでした。演出→自動投稿の順にすれば体験を統一できます。
- **パンジローの表情素材**：現在は normal / happy / sleepy の3枚を流用しています。「泣いて喜ぶ」「ダンベルを持つ」などの専用差分が届けば、`PJ_*` の `pose` を差し替えるだけで反映できます（コード変更不要）。
- **部屋側の NEW 強調**：家具のWebP素材が未着のidが多く、部屋での「光る」演出は素材のある家具のみに限られます。素材追加で自動的に効きます。
- **効果音**：フェーズ管理を分離してあるので、後から `phase===2` に1音だけ足す形で拡張できます（無音優先の設計は維持）。
- **リアクションの偏り防止**：直近に出たidを避ける仕組み（保存不要・メモリのみ）を入れるとさらに新鮮になります。

---

**合言葉**：少し動いて、たくさん褒められる。
ユーザーは運動するためではなく、パンジローに報告するためにアプリを開く。

# v38.1 修正（演出の落ち着かせ・パンジロー大型化）

## 1. 回転する背景を完全廃止
`.pj-rays` の `repeating-conic-gradient` と `@keyframes pjSpin`（16秒無限回転）を、
CSS・JSXの両方から**削除**しました。背景は淡い固定グラデーションのみです。
光るのは登場時の `pj-flash`（0.5秒・1回だけ）に限定しています。

## 2. パンジローを大胆に拡大（根本原因も修正）
既存の `panda30_*.webp` は **1536×1024の「部屋レイヤー全体」**で、
パンダ本体は画像の幅のわずか **約16%**（happyで1536px中253px）しか占めていませんでした。
これが「小さく見える」本当の原因です。

そこで**リアクション専用の切り出し素材**を新規追加しました。

| ファイル | サイズ | 容量 |
|---|---|---|
| `assets/panda-room/v38/pj38_normal.webp` | 508×740 | 35KB |
| `assets/panda-room/v38/pj38_happy.webp` | 606×774 | 39KB |
| `assets/panda-room/v38/pj38_sleepy.webp` | 486×512 | 23KB |

合計約98KB。既存の `panda30_*.webp` は**一切変更・削除していません**（部屋はそのまま）。

表示サイズ：

| 状態 | 幅 | 最大幅 |
|---|---|---|
| 通常のリアクション中 | 画面幅の **82%** | 320px |
| ドアップ／激レア | 画面幅の **92%** | 340px |
| メッセージ表示後（静止時） | 60% | 224px |
| 高さ700px未満の端末 | 76% / 84% | 252px / 268px |

読み込み失敗時は `pj38_normal.webp` → 絵文字🐼（150px）の順にフォールバックします。

## 3. 動き続けるアニメーションを全廃
17種すべての `infinite` を撤廃し、**1〜4回で必ず止まる**ようにしました。
全キーフレームの100%が静止状態なので、回数を終えるとそのまま自然に落ち着きます。

| しぐさ | 回数 × 時間 | 合計 |
|---|---|---|
| ジャンプ | .58s × 2 | 1.16s |
| 拍手 | .40s × 3 | 1.20s |
| ダッシュ／ズーム／寝起き／通り過ぎ | × 1 | 0.5〜1.5s |
| ゴロゴロ／伸び／ゆらゆら | × 1 | 1.4〜1.6s |
| ガッツ／万歳／歩く／ダンベル／小さく／王冠 | × 2 | 1.56〜1.7s |
| 息切れ | .36s × 4 | 1.44s |

リアクション時間を1.4秒→**1.7秒**に伸ばし、すべてのアニメーションが
メッセージ表示前に**動き終わる**ようにしました（途中で切れて不自然に止まりません）。

## 4. 登場は画面下から飛び出す形に
`pjEnter` を `translateY(130px) scale(.5)` から始まる軌道に変更。
下から大きく飛び出して、少しオーバーシュートしてから収まります。

## 5. メッセージ表示後は完全に静止
phase 3 に入ると `settled` クラスが付き、`animation:none` ＋ サイズ縮小（0.45秒のトランジション）。
パンジローは動きを止めて、読みやすい状態に落ち着きます。

## 6. 紙吹雪の範囲
通常記録では出ません。**激レア3種と、節目の30/50/100回のみ**です。

## 演出全体の長さ

```
フラッシュ 0.26s → 登場 0.5s → リアクション 1.7s → メッセージ（静止）
```
合計約2.5秒。画面のどこをタップしても、右上の「スキップ」でも即座に飛ばせます。
