# ゆるトレ倶楽部 v42 — パンダルーム「パンジロー生活システム」

パンジローの**常時左右に揺れる／傾く待機アニメーションを廃止**し、
「静かに過ごしている → ときどき別のことをしている」生活行動システムへ置き換えました。

> パンダルームを開いた瞬間に「今日は何してるかな？」と思える場所にする。
> 家具を見る画面 → **パンジローに会いに行く場所**へ。

## 3. 生活状態の決定ロジック

### 6つの生活状態

`normal` / `window` / `eat` / `relax_floor` / `workout` / `sofa`

### 時間帯ごとの出現確率

**既存の `roomDisplayBand()` の `band.id` をそのまま使用**しています。
新しい時間判定システムは作っていません（窓の時間帯処理にも一切触れていません）。

| band.id | 時刻 | 確率 |
|---|---|---|
| `morning` | 5–11時 | window 40 / normal 30 / workout 20 / sofa 10 |
| `noon` | 11–16時 | workout 30 / normal 25 / window 15 / eat 15 / relax_floor 15 |
| `evening` | 16–19時 | eat 35 / window 25 / sofa 20 / normal 10 / relax_floor 10 |
| `night` | 19–23時 | sofa 40 / relax_floor 25 / eat 15 / window 10 / normal 10 |
| `deepnight` | 23–5時 | relax_floor 60 / sofa 30 / normal 10 |

**深夜に `workout` は出ません**（テーブルに存在しないため構造的に出ない）。

### 一定時間は同じ行動を維持する

毎回ランダムだと人工的に見えるため、**決定的（deterministic）に選択**しています。

```
seed = fnv1a( ユーザーID + "|" + ローカル日付 + "|" + band.id + "|" + 時間ブロック )
時間ブロック = floor( (時*60 + 分) / PANDA42_BLOCK_MIN )     ※ PANDA42_BLOCK_MIN = 60分
```

- **同じ時間ブロックの間は、閉じて開き直しても必ず同じ行動**（検証で一致率100%）
- 日付が変わると必ず変わるため、毎日同じパターンにはならない
- **localStorage は一切増やしていません**（その場で計算するだけ）

固定時間を変えたい場合は `PANDA42_BLOCK_MIN` の数値だけ直してください（30〜90分の範囲を想定）。

### 運動記録との連動（さりげなく）

当日の運動記録があると `workout` の**出現率**を1.5倍にします。

| | 通常 | 当日運動あり |
|---|---|---|
| 昼 | 30% | **45%** |
| 朝 | 20% | **29%** |

※「重みを1.5倍」ではなく「出現率が1.5倍」になるよう解いています（重みだけ増やすと母数も増え、30%が39%にしかならないため）。
※ 競争・連続記録・煽り要素は一切入れていません。「ユーザーが運動したから、パンジローも少しやる気になった」程度の表現です。

### ラーメン棚との連動

`ramen_shelf` 解放済みなら `eat` の出現率を1.15倍（夕方 35% → 約41%）。

## 4. 家具未解放時のフォールバック内容

**その家具が無いのに、その家具を使う行動は絶対に選びません。**

| 行動 | 必要な家具 | 未解放時の振り替え先 |
|---|---|---|
| `sofa` | `sofa` | `relax_floor`（朝のみ `normal`） |
| `workout` | `dumbbell` | `normal` |
| `eat` | テーブル（初期家具） | 振り替えなし。常に使用可能 |

振り替えは**確率を捨てずに合算**します（例：夜にソファ未解放なら sofa 40% が relax_floor へ回り、relax_floor 67%）。

実測（両方未解放の場合）：

```
morning    normal 60.0%  window 40.0%
noon       normal 55.6%  eat 15.9%  window 15.5%  relax_floor 13.0%
evening    eat 35.8%  relax_floor 31.0%  window 24.6%  normal 8.6%
night      relax_floor 67.1%  eat 13.0%  window 10.9%  normal 9.0%
deepnight  relax_floor 91.7%  normal 8.3%
```

## 5. 素材未配置時のフォールバック内容

v42の立ち絵はまだ存在しないため、**READY方式**で安全に無効化しています。

```js
const PANDA42_READY=[];   // ← 素材を置いた行動のidだけを足す
```

- READYに無い行動は **v42のパスへ `<img>` を生成しません** → **404は1件も出ません**（実ブラウザで検証済み）
- 代わりに既存の `assets/panda-room/v30/` の立ち絵を、**従来どおり全面レイヤーのまま**表示します
- **CSSで回転・横倒しはしません。既存画像を加工して「寝ている風」にもしません**
- タップ領域も、フォールバック中は従来の `ROOM_PANDA_SPOT` のままです（絵と領域がずれないため）

| 行動 | フォールバック先（v30） |
|---|---|
| `normal` / `window` / `workout` / `sofa` | `panda30_normal.webp` |
| `eat` | `panda30_ramen.webp` |
| `relax_floor` | `panda30_sleepy.webp` |
| タップ直後（happy） | `panda30_happy.webp`（従来どおり優先） |

二重の保険として、万一 v42 画像の読み込みに失敗した場合も `panda42ImgFail` で v30 へ戻ります。

### 素材が届いたら

1. 6つのWebPを `assets/panda-room/v42/` に置く
2. `PANDA42_READY` に id を足す（例 `['window','sofa']` のように一部だけでもOK）

コードの他の変更は不要です。位置は `PANDA42_ACTIONS` の数値だけで調整できます（JSXにベタ書きしていません）。

## 6. `?action=` デバッグ方法

既存の `?debug=1` / `?hour=0〜23` はそのまま維持しています。加えて：

```
?action=normal
?action=window
?action=eat
?action=relax_floor
?action=workout
?action=sofa
```

- 生活状態を強制表示します。**本番UIには一切表示されません**（URLに付けたときだけ有効）
- 組み合わせ可： `?debug=1&hour=21&action=sofa`
- `?debug=1` の自己診断パネルに以下を追加しました：

```
action: sofa (?action=強制)
asset42: 未配置→v30 / 当日運動: なし
sofa: 解放 / dumbbell: 未解放 / ramen_shelf: 解放
```

各ポーズの位置合わせは、この `?action=` で固定表示しながら `PANDA42_ACTIONS` の数値を直すのが最短です。

## 7. 動きについて（§10）

「生きている感 ＝ 激しく動くこと」ではない、という方針で作っています。

| 行動 | 動き |
|---|---|
| `normal` | 5秒周期のごく小さい呼吸（scale 1.2%）のみ |
| `window` | ほぼ静止。22秒に一度だけ頭を1.4度傾ける |
| `eat` | 常時上下させない。9秒周期のうち最初の約2秒だけ小さく食べるしぐさ |
| `relax_floor` | ほぼ静止。寝息程度の呼吸のみ |
| `workout` | 3回だけ動いて、残り約11秒はしっかり休む（永久に上げ続けない） |
| `sofa` | ほぼ静止。座ったまま静かに呼吸 |

まばたきは従来どおり `filter` のみ（移動しません）。

## 8. 既存機能を変更していないこと

以下は**一切変更していません**（実ブラウザで動作確認済み）。

- **夜景システム**：`room30_window_evening/night/deepnight.webp` / `ROOM30_WINDOW_READY` / `ROOM_WINDOW_VER` / `windowNightSrcFor()` — 無変更
- **家具システム**：`ROOM41_SLOTS` / `room41Layers()` / `ROOM41_REFLECTED` / アンロック条件 / 家具保存データ
- **レイヤー構造**：背景 → 窓 → 家具 → 夜色 → パンジロー → 暖色レイヤー（この順序のまま）
- 通知 / Supabase / 認証 / SNS / 運動記録保存 / ミッション / ポイント
- Welcome画面 / パンダルーム / パンダ相談室 / タイムカプセル / 既存画像
- 既存の会話DB `ROOM_TALK_DB` は**削除していません**。行動別セリフと混ぜています
  （タップ時：行動別40% / なでなで30% / 従来の状況会話30%）
- `onPandaTap` と `panda_tap` 計測、💕🎵✨ の演出 — 維持
- `@media (prefers-reduced-motion: reduce)` — 維持。v42のクラスをすべて登録済みで、
  モーション低減端末では**生活状態の画像だけ切り替わり、アニメーションは完全に停止**します（検証済み）

### 後方互換

**localStorageのキーを1つも追加・変更・削除していません。**
生活状態はその場の計算のみで決まるため、既存ユーザーの panda stats / room settings / 家具解放 /
運動記録 / ミッション / ポイントはそのまま引き継がれます。

### タップの優先順位について（既知の仕様）

`sofa` 行動のときは、パンジローのタップ領域がソファの家具ホットスポットと重なります。
パンジローのボタンが上（z-index 9 > 8）なので、**その間はソファをタップすると
パンジローが反応します**。§12「パンジローがどこにいてもタップできる」を優先した結果です。
