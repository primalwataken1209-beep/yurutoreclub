目的: 別ユーザー（前回の体験版・別アカウント）のパンジロー会話ログが見える可能性をなくすこと。修正はこの1点のみです。

## 3. 旧会話ログの保存方式
- キー: `yurutore_room_talklog_v1`（全ユーザー共通の1つだけ）
- 誰が使っても同じキーに追記し、同じキーを表示していたため、同じ端末なら前回の体験版や別アカウントの会話も見えていました。

## 4. 新しい会話ログの保存方式
- ログインユーザー: `yurutore_room_talklog_v1_<userId>`
- 体験版: `yurutore_room_talklog_v1_guest`
- 中身の形式（`[{text, ts}]`、新しい順・最大30件）は変更なし。

## 5. guest（体験版）の扱い
- 体験版の会話は guest 専用キーに保存されます。ログインユーザーのキーとは完全に別です。
- **同じ体験版を続けている間**: ページを再読み込みしても会話ログは残ります（再読み込みでは初期化処理が呼ばれないため）。
- **新しく体験版を始めたとき**: v51.4.4 の `ytResetGuestRoomIfFresh()` が「体験版の初期設定の完了時」かつ「体験版の記録などが全て空」の場合だけ動き、そこで guest 会話ログも消します。体験版を終える（ログアウトする）と記録が空に戻るため、次の体験版では前回の会話が出ません。

## 6. 旧共通キーの扱い
- **読み込まない・移行しない**: 誰の会話か判別できないため、どのユーザーにも引き継ぎません。アプリの画面には表示されなくなります。
- **起動時の自動削除はしていません**: 削除しなくても表示されず、機能にも影響しないためです。退会処理の削除リストには従来どおり残しています（今は誰も読まないキーなので、消しても他のユーザーに影響しません）。
- 端末の中には、旧キーの中身が退会するまで残ります（下の「見つけたが修正していない点」1）。

## 7. 退会時の扱い
- 退会した本人のキー `yurutore_room_talklog_v1_<本人のuserId>` を削除します。
- 他のユーザーのキーと guest のキーは削除しません（テスト10で確認）。
- 認証・退会そのものの処理（Edge Function 呼び出し、サインアウト、画面遷移）は変更していません。変えたのは削除するキー名のリストに1行足しただけです。

## 8. テスト方法
- ヘッドレスChromium（幅390px）で、本番と同じ版の React／Babel を読み込み、実際に画面を操作しました。
- Supabase には接続できないため、ログイン部分だけ**模擬のSupabaseクライアント**に差し替えました。セッションのユーザーIDとして `userA` / `userB` を返します。アプリのコード自体は納品物そのままです。
- 「会話」はパンダルームをタップして、パンジローに話させる操作です。毎回、会話ログ画面に表示された内容と、そのユーザー用キーの中身が完全に一致することを確認しました。
- 名前入りのセリフ（「userAさん」など）が別ユーザーの画面に出ないことも確認しました。
- 旧共通キーには目印の文字列「旧共通キーの秘密ログ」を事前に入れておき、どこにも表示されないことを確認しました。

## 14. 見つけたが修正していない点（報告のみ）
1. **旧共通キーの中身が端末に残る**: 画面には出ませんが、以前の誰かの会話が `yurutore_room_talklog_v1` に残ったままです。完全に消したい場合は、起動時に旧キーを1回だけ削除する処理を足せます（1行・機能への影響なし）。
2. **来店記録 `yurutore_daily_visit_v1_guest` が体験版で共通**（v51.4.4から継続）: 前回の体験版の来店日をもとに「おかえり」系のあいさつが出る可能性があります。会話の中身は含みません。
3. **ルーム設定 `yurutore_room_settings_v1` がユーザー共通**: 中身は動き・効果音・夜間モードの設定だけで、個人の内容は含みません。
4. **パンダ相談室の「前回の返信番号」`yurutore_last_panda_reply_{カテゴリ}` がユーザー共通**: 中身は数字だけで、会話の内容は含みません。相談室の会話本文はユーザー別の state に保存されています。
5. **PCのデバイスプレビュー**（v51.4.4から継続）: iOS枠とAndroid枠で guest のキーを共有します。PCプレビューだけの現象です。
6. `app.js` 先頭コメントのバージョン表記が v51.4.2 のままです（動作に影響なし）。
