# ゆるトレ倶楽部 v41 — パンダルーム「育つほど、整って可愛くなる部屋」

35点すべてを床と壁に並べる方式をやめ、**部屋に定位置（スロット）を先に決めて、
解放した家具がそこへ入る**構造に作り替えました。
アンロック条件・保存・既存ユーザーの復元・初回のみ通知は **v40のまま変更していません**。

---

## 1. 何が変わったか

```
v40:  解放した家具の数 = 画面に並ぶ物の数（最大32個が床と壁に散らばる）
v41:  解放した家具の数 = 部屋の充実度      画面に並ぶ物 = 最大19レイヤー
                                          （うち独立した大きな物体は約14）
```

- 同じ役割の家具は **交換**（収納3段階・ラグ2段階・卓上照明2段階・ぬいぐるみ3種・壁の主役2種）
- 小物は **親家具の絵に統合**（クッションとブランケットはソファへ、写真立てと小さな植物は本棚へ、
  ピザとのれんはラーメンコーナーへ）
- 壁面装飾は **4か所まで**
- 家具は1つのレイヤーに入り、**パンジローより前には構造上出られない**

## 3. アートスタイルの作り直し

v40の家具は「黒い太線＋ベタ塗り＋原色寄り」で、背景の水彩画と馴染んでいませんでした。
v41では描画エンジンから作り直しています。

| v40 | v41 |
|---|---|
| 黒に近い太い輪郭（5px） | 焦げ茶の細い輪郭（0.75px相当・半透明140/255） |
| 単色ベタ塗り | 上下グラデーション＋内側の影＋上部のハイライト |
| 原色の赤・青・黄・緑 | ナチュラルウッド／アイボリー／ベージュ／淡いミント／くすみオレンジ／淡いブラウン |
| 接地影がバラバラ | 全家具で統一したやわらかい接地影 |

**パレット**：`#e2c6a0` ウッド ／ `#faf4e9` アイボリー ／ `#eee0ca` ベージュ ／
`#c4dcce` 淡いミント ／ `#e4b694` くすみオレンジ ／ `#c6ac92` 淡いブラウン ／ `#fcead0` 暖色光

**ソファ**は部屋の象徴家具として作り直しました。ふっくらした布地（背もたれ／背クッション／
座面／肘掛けを別レイヤーで陰影づけ）、木製脚、座面の縫い目、クッションとブランケットが
段階的に増える3枚構成です。

## 6. パンジローを主役に保つ

- パンジローの矩形（左45.4%〜61.9% / 上52%〜85%）に家具は入りません。
  唯一、手前の肉球ラグが足元で1.9%重なりますが、**ラグは家具レイヤー内＝パンダより背面**なので、
  パンダが上に描かれます（隠れません）。
- パンジローの左右と頭上には家具を置かない余白を確保しています。
- 部屋の中央手前の床は、最終状態でも空けたままです。

**視線の順序**：パンジロー → 温かい部屋 → 最近増えた家具（解放時は1秒だけそのスロットが光ります）。

## 7. z-index の整理

家具は `.room-furn41-layer`（`z-index:2`）という1つの容器に入れ、その中で以下の帯を使います。
容器が重ね合わせコンテキストを作るため、**どの家具もパンダ（`z-index:4`）より前には出られません**。

| 帯 | z | 中身 |
|---|---|---|
| 壁面 | 10〜13 | ガーランド・ネオン／ポスター・時計・ウォールシェルフ・ラーメンコーナー・窓辺のチャーム |
| ランプの光 | 19 | 静止した暖色のにじみ |
| 床のマット | 20 | 肉球ラグ／小さなラグ |
| 床の大型家具 | 30〜32 | ソファ・収納家具・本棚・観葉植物・フロアランプ |
| 家具の上の小物 | 40〜42 | 卓上照明・写真立て・マグ・ティッシュ・クッション |
| 床の手前の小物 | 50〜51 | ぬいぐるみ・運動コーナー・スリッパ |

接地位置は下端で指定し、上端を高さから自動計算しています。
「家具の上に載る小物」は `onTopOf` で親の天板に自動で吸着するので、
収納家具が3段階で入れ替わっても、卓上ライトが浮いたり沈んだりしません。

## 8. 照明

フロアランプを解放すると、周囲に**静止した**淡い暖色のにじみを1枚重ねます。
夜（21時以降）は `is-night` クラスで不透明度を 0.55 → 0.8 に上げるだけです。
**点滅・回転・明滅は一切ありません。** アニメーションの追加はゼロです。

## 9. ラーメン要素

床に大きなラーメンアイコンを置くのをやめ、**右奥の壁の「ラーメンコーナー」1枚**にまとめました。
棚板の上に丼が2つ、下に小さな暖簾、その下に小皿。
よく見ると「パンジローはラーメンが好きらしい」と分かる程度の存在感です。

## 11. 素材を差し替えたくなったら

`assets/panda-room/v41/` の同じファイル名で置き換えるだけで反映されます。
コード変更は不要です（サイズは `ROOM41_SLOTS` の `w` と `h` で決まるので、
縦横比を変える場合だけ `h` の調整が必要です）。

将来もっと良い素材が手に入ったときは、この方式でそのまま差し替えられます。

---

**目指したもの**：家具を全部集めたゲーム画面ではなく、
「パンジローが本当にここで暮らしていそうな、温かくて可愛らしい部屋」。
数か月後に初期状態と見比べたとき、「こんなに素敵な部屋になったんだ」と思える状態にしました。
