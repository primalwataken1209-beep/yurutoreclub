## 2. それでも実機で夜にならない場合に備えた堅牢化

実ブラウザで再現しなかったため、**環境側で起こりうる失敗モードを塞ぐ修正**を入れました。

### ① 室内の明るさ設定と切り離した（重要）

```js
// 旧： {!baseFallback && lightBg && (band.id==='night'||…) && …
// 新： {!baseFallback &&            (band.id==='night'||…) && …
```

`lightBg` は「部屋のライティング」で、**設定の「常に明るい」を選ぶと `null`** になります。
旧コードではこのとき窓の夜景まで消えて、**窓だけ昼のまま残る**状態になっていました。
窓の外は外の世界なので、室内の明るさ設定とは無関係に切り替わるようにしました。

### ② `windowImgOk` が false のまま固定されないように

```js
const winSrcKey = windowNightSrcFor(roomDisplayBand(roomHourOverride()).id) || '';
useEffect(()=>{ setWindowImgOk(true); }, [winSrcKey]);
```

一度でも読み込みに失敗すると `false` のまま固定され、時間帯が変わっても夜景imgが
生成されなくなる状態でした。**夜景srcが変わるたびに true へ戻します。**

### ③ 失敗時にDevToolsで原因が分かるように

読み込み失敗時、実際のURL付きで `console.warn('[panda-room] 窓の夜景素材を読み込めませんでした:', src)` を出します。

### ④ キャッシュ版数を `?v=413` へ

CDN/ブラウザが旧ファイルを掴んだままにならないよう更新しました。

### ⑤ 自己診断表示（`?debug=1` のときだけ）

URLに `?debug=1` を付けたときだけ、パンダルームの下に1行で状態が出ます。

```
hour: 20 / band: night
window: room30_window_night.webp
windowImgOk: true / baseFallback: false / night: auto
```

**通常アクセスでは一切表示されません**（`?debug=1` が無ければDOMごと生成されません）。
実機で夜にならないときは `?hour=20&debug=1` を開いて、どの値が想定と違うか確認できます。

| 表示 | 意味 |
|---|---|
| `window: (なし)` | 時間帯判定が夜になっていない、または READY 未登録 |
| `windowImgOk: false` | 画像の読み込み失敗（404・パス・デプロイ漏れ） |
| `baseFallback: true` | `room30_base.webp` 自体が読めていない |
| `night: bright` | 「常に明るい」設定（②の修正後も室内は明るいまま／窓は夜になります） |

## 3. 4時刻の比較（実ブラウザ・iPhone 390px）

`?hour=12` / `?hour=17` / `?hour=20` / `?hour=0` を実際に開いて撮影したものです。

- **12:00** 青空・白い雲・桜のピンク
- **17:00** 夕焼けのオレンジと沈む太陽
- **20:00** 濃紺の夜空・月・星・遠くの家あかり
- **0:00** さらに深い紺（パンジローも眠そうな表情に）

**12:00と20:00は、説明なしでも別物と分かる差**になっています。

## 4. デプロイ後にご確認いただきたいこと

実装側は実ブラウザで検証済みなので、残る可能性はデプロイ／キャッシュ側です。

1. `?hour=20&debug=1` を開き、`windowImgOk: true` / `baseFallback: false` / `window: room30_window_night.webp` になっているか
2. DevTools の Network で `room30_window_night.webp?v=413` が **200** で返るか（404ならデプロイ漏れ）
3. 公開先に `assets/panda-room/v30/room30_window_night.webp` `_deepnight.webp` `_evening.webp` の**3ファイルが実在するか**
4. 「常に明るい」設定にしていないか（②の修正で窓は夜になりますが、室内は明るいままです）
5. スーパーリロード（キャッシュ無効）で確認
