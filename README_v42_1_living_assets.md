## 3. 切り抜き／透明化の方法

### 背景の除去

**結論：透明化で品質が崩れた箇所はありません。**

支給された4枚の元PNGには、**すでに正しいアルファチャンネルが入っていました**
（RGBには暗いグラデーション背景が残っているものの、アルファ側でパンジローの形が抜かれている状態）。
そのため背景除去そのものは不要で、こちらでは以下だけを行いました。

1. **ポーズの分離** — `02_living_pose_sheet.png` はアルファの**連結成分ラベリング**で6つの塊に分け、
   各ポーズに属する成分だけを残しました。単純な矩形切り出しではないので、
   隣のポーズが1ピクセルも混入していません。
   小さな装飾（ゴロ寝の「Z」3個、筋トレの汗4個）も、位置から所属ポーズへ割り当てて一緒に残しています。
2. **フチの色補正（デカール除去）** — アルファが 0 < a < 210 の半透明フチには、
   元の暗い背景色が残っています。この画素のRGBを、近傍の不透明画素の色で置き換えました
   （アルファの形状は変更していません）。明るい部屋に重ねたときに黒フチが出ないようにするためです。
   ※パンジローの頭の毛にある暖色のリムライトは**元絵の一部**なので残しています。
3. **トリミングとリサイズ** — 不透明部分のバウンディングボックス＋2pxで切り詰め、
   表示サイズの約1.6倍（Retina用の余裕）へ LANCZOS で縮小。元より大きくは拡大していません。
4. **WebP書き出し** — quality 88 / method 6。

## 4. 二重表示の対策（§7）— `hide` 方式

素材の中に部屋と同じ家具が描かれているポーズがあります。
そのまま重ねると「ソファが2つ」「テーブルが2つ」になるため、
**そのポーズのあいだだけ、対応する家具レイヤーを描かない**仕組みを入れました。

`PANDA42_ACTIONS` の `hide` に家具のidを書くだけで効きます（v30アイテムid / v41スロットkey のどちらでも可）。
ハードコードはしていません。

| ポーズ | 隠す家具 | 理由 |
|---|---|---|
| `sofa` | `sofa` | 素材にソファ本体が描かれている。**「ソファの前に立っている」ようにも「ソファが二重」にも見えない** |
| `workout` | `gym` | 素材にダンベルが描かれている（部屋のジムコーナーと重複） |
| `eat` / `pizza` / `beer` | `table` `mug` `tissue` | 素材に小さなテーブルがある。**テーブルの上に載っているマグとティッシュも一緒に隠さないと宙に浮く** |
| `normal` / `window` / `relax_floor` | — | 重複なし。`relax_floor` のラグは部屋のラグに重なって自然に見えるので隠していない |

隠した家具は**タップ領域（ホットスポット）も同時に消える**ので、見えない家具を触れてしまうことはありません。
素材の読み込みに失敗して v30 立ち絵へフォールバックしたときは、`hide` は適用されません（家具を消す理由がないため）。

### タップ領域について（§8）

横長ポーズ（`relax_floor` / `pizza` / `beer` / `sofa`）は**立ち絵用の固定領域を流用していません。**
各素材の中で「パンジロー本体」が写っている範囲を実測し、ポーズごとに個別の `tap*` を持たせています。
たとえば `beer` は絵の左3割がテーブルと枝豆なので、タップ領域はパンジロー側（39.06%〜）から始まります。

`onPandaTap` と `panda_tap` 計測、💕🎵✨ の演出はそのまま維持しています。

### ★セーフバンド（今回いちばん重要な調整）

スマホでは部屋（比1.5）がカードより横に広く、中央寄せで横スクロールします。
実測すると、**320px幅の端末が最初に見せているのは stage の 28.6%〜71.4% だけ**でした。

初期の配置（ソファを部屋の左隅＝1.5%〜、ラーメンをテーブル位置＝17.5%〜 に置く案）では、
**`sofa` はスワイプするまで画面に一切出てこない**という状態になっていました（§12の禁止事項）。

そこで**全8ポーズを left ≥ 29% / right ≤ 71% に収め直しました。**
その結果、部屋のソファ／テーブルの実際の位置とはずれるため、
`sofa` と `eat`/`pizza`/`beer` では上記のとおり該当家具を `hide` して、
「素材の中の家具」を唯一のソファ／テーブルとして見せています。

## 6. ピザの出現ロジック（§5）

- `eat` が選ばれたとき、その内訳として **ラーメン75% / ピザ25%**
- **v42と同じ決定的シード**を使用：`fnv1a('meal' | ユーザーID | ローカル日付 | band.id | 60分ブロック) % 100 < 25`
- 同じ時間ブロックの間は、閉じて開き直しても変わりません
- 新しいlocalStorageキーは追加していません（その場で計算するだけ）

実測（800日×24ブロック）：`noon` ラーメン72.8% / ピザ27.2%、`evening` 72.7% / 27.3%、`night` 72.0% / 28.0%

ピザ専用セリフ（既存の会話DBと混ぜて使用）：
「ピザは別腹だよ〜🍕」「一枚だけのつもりだったんだけど…」「チーズ伸びすぎ〜！」「運動したからゼロカロリー…ってことで🐼」

## 7. ビールのレア出現ロジック（§6）

**通常行動ではありません。** `PANDA42_WEIGHTS`（生活状態の確率表）には入れていません。
唯一の出現経路は「夜に選ばれた `sofa` または `eat` を置き換える」だけです。

```
条件: band.id === 'night'（既存の時間帯判定＝19:00〜23:00）
      かつ 基本行動が sofa または eat
確率: fnv1a('beer' | ユーザーID | 日付 | band.id | 60分ブロック) % 100 < 12
```

実測（800日×24ブロック）：

| 時間帯 | base=sofa | base=eat |
|---|---|---|
| morning | 0.0% | 0.0% |
| noon | 0.0% | 0.0% |
| evening | 0.0% | 0.0% |
| **night** | **12.0%** | **12.0%** |
| deepnight | 0.0% | 0.0% |

- `sofa` / `eat` 以外の行動から出た回数：**0回**（400日×24ブロック×4行動×5時間帯で検証）
- 1人のユーザーの1年間：**ビールに出会えた夜は 92/365日（25.2%）／連続最長4日**
  → 「毎晩固定」にはならず、「たまに見つけると嬉しい」レア度になっています
- 同じ時間帯に再読み込みしても変わりません
- **ユーザーが選択するUIは作っていません**

専用セリフ（ねぎらいと「のんびり」だけ。**飲酒をすすめる表現・健康効果を示唆する表現は入れていません**）：
「今日はおつかれさま〜🐼」「ぷは〜……って言ってみたかった」「枝豆も欲しくなってきた…」「今日はのんびり夜です」

なお、夜の基本行動が `sofa` のときにビールへ置き換わった場合は、パンジローは床のクッションで飲んでいる絵になります。
このときソファは隠さないので、ソファが消えることはありません。

既存のものはそのまま維持しています。

```
?debug=1
?hour=0〜23
?action=normal / window / eat / relax_floor / workout / sofa
```

今回の追加：

```
?variant=ramen / pizza / beer
```

組み合わせ例：

```
?debug=1&action=eat&variant=pizza
?debug=1&action=sofa&variant=beer

```

`?variant=` は位置合わせ用の強制表示なので、時間帯や家具の条件を無視して直接そのポーズを出します。

```

asset42: あり / 当日運動: なし
sofa: 解放 / dumbbell: 解放 / ramen_shelf: 解放
```

素材が変わっても、v42の方針（静かに過ごす／激しく動かさない）は維持しています。
